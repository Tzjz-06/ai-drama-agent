# Mermaid 设计图纸

这些 `.mmd` 文件描述当前项目的实际结构：

- `01-system-architecture.mmd`：客户端、Web API、制作流水线和模型适配器。
- `02-production-data-flow.mmd`：从剧本文本到 `DramaProject` 和制作包的生成链路。
- `03-cloud-deployment.mmd`：Docker + Caddy 的 HTTPS 云端部署拓扑。
- `04-auth-and-sync-sequence.mmd`：登录、保存和多端 revision 同步时序。

可使用 Mermaid Live Editor、VS Code Mermaid 插件或 Mermaid CLI 渲染。
