# 模型配置中心规则

## 稳定事实

- 文本、图片、视频三类配置都只保存在当前浏览器会话，不写入项目数据或 `data/app_state.json`。
- 每类配置都支持多条记录，使用 `enabled`、`priority`、`is_default` 决定当前生效项。
- 文本配置支持两种模式：`manual` 的 OpenAI-compatible 接口，以及 `cc_switch`。
- 图片和视频配置支持各自的 OpenAI 预设，也支持“兼容接口（高级）”。
- API Key 只允许在连接测试或任务提交时临时发送，不得写入前端构建产物、项目 JSON 或本地持久化任务数据。

## 禁止事项

- 不得把 API Key 写入项目、章节、生产包、`app_state.json` 或前端 bundle。
- 不得把“已填写 API Key”误判成“配置可用”，必须通过真实连接测试。
- 不得把不支持的配置类型静默降级成别的供应商。

## 推荐排查顺序

1. 先检查当前类别是否存在启用项，以及是否有默认配置。
2. 再检查配置模式、模型名、Base URL 或 API 地址是否完整。
3. 然后跑真实连接测试，确认 HTTP 状态和返回模型名。
4. 最后再提交生成任务，确认本地任务数据里没有 `provider_config`。

## 验收标准

- 配置中心可以新增、编辑、删除、启用、停用和设为默认。
- 图片/视频任务只使用当前启用配置，且任务记录中不包含 API Key。
- 桌面版关闭浏览器会话后，配置不再可见。
